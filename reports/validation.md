# 公开工具验证记录

验收日期：2026-11-13。

在 Linux 主机上以 C++17 编译采样工具，开启 `-Wall -Wextra -Werror -pedantic`。
通过统一入口运行 **13 个测试，全部通过**：

```sh
make test ARTIFACT_DIR="$ARTIFACT_DIR"
```

`ARTIFACT_DIR` 须设置为源码目录以外的临时产物绝对路径。

| 验证范围 | 实际检查 |
|---|---|
| 采集到统计的链路 | 对合成节点采集三个样本，校验数值和单调时间戳，再通过命令行汇总 CSV |
| 连续采集退出 | 等待实际样本写出后发送 `SIGTERM`，检查进程正常退出 |
| 文件保护 | 采样和汇总均拒绝覆盖已有文件，并验证原文件内容保持不变 |
| 节点输入错误 | 检查缺失节点、空内容、尾随垃圾、整数溢出、嵌入空字节和过长内容 |
| 调用参数错误 | 检查非法样本数 |
| 统计正确性 | 检查分类统计、负数及偶数样本中位数 |
| CSV 错误 | 检查缺失与重复列、空数据、非法及非有限数值、多余字段和分组列冲突 |

测试数据均由本仓库生成或明确标记为合成输入。本记录验证公开工具的主机功能，
不包含真实设备测量，也不代表完整研究项目的性能或正确性验收。
GitHub Actions 的后续运行结果可在仓库 Actions 页面独立查看。
